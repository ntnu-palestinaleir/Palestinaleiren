# 🇵🇸 NTNU Palestine Student Encampment – “Link-in-bio” Page

This repository contains the simple “link-in-bio” website for the **Palestinian Solidarity Camp at NTNU**. The site acts as an accessible hub with updated information about the encampment, upcoming events, social media, and other relevant resources.

The website is static and minimal — plain HTML/CSS/JS — and designed so anyone involved in the camp can maintain it without hassle.


## Structure

* **index.html** – Main landing page
* **kalender.html** – Overview of upcoming events
* **om-oss.html** – “About us” page (information about the camp)
* **styles.css** – Basic styling
* **scripts.js** – JavaScript for interactivity (if any)
* **images/** - Assets like images etc.
* **fontawesome/** - Icons
* 🚧***hjelpe.html***🚧 –  List of ways to help Palestine (coming soon)


## Hosting

The site is hosted using **GitHub Pages** and updates automatically whenever changes are pushed to the `main` branch.

## How to Contribute

If you’d like to add or update something:

1. Fork the repo
2. Create a new branch
3. Make your changes
4. Open a pull request

All contributions are welcome — whether it’s fixing a typo or improving layout and content.


## Purpose

The goal of this site is to offer a simple, clear overview of the camp — who we are, what we’re doing, and how people can take part.

The page is designed to be:

* easy to navigate
* quick to update
* mobile-friendly
* practical for sharing on Instagram and other social platforms
